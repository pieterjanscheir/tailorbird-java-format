Every Java team has a style. Most formatters only know one.

So I built Bowerbird, an open-source Java formatter where every rule is a setting.

🪶 One bowerbird.yml. List only the rules you want to change: indent, continuation indent, import groups, brace spacing and more.
✅ The default style matches IntelliJ IDEA's formatter, so the IDE and CI agree.
🧩 Start from the Palantir or Google preset and tweak from there.
🔧 Gradle, Spotless, IntelliJ and the CLI all read the same file.

It's based on palantir-java-format and released under Apache 2.0.

Docs: https://pieterjanscheir.github.io/bowerbird-java-format/
GitHub: https://github.com/pieterjanscheir/bowerbird-java-format
